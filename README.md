# 🛒 GreenCart – Fullstack Grocery Store App

![GreenCart Banner](https://greencart-client-lyart.vercel.app/logo192.png)

**Live Site:** 🌐 [https://greencart-client-lyart.vercel.app](https://greencart-client-lyart.vercel.app)

GreenCart is a modern fullstack e-commerce web application for grocery shopping — built using the **MERN stack** (MongoDB, Express, React, Node.js).  
It allows users to browse products, add items to cart, manage orders, and complete purchases in a simple, clean interface.

---

## 🌐 Live Demo
🚀 **Visit GreenCart here:**  
👉 [https://greencart-client-lyart.vercel.app](https://greencart-client-lyart.vercel.app)

---

## 🧠 Features

- 🏠 **Modern React Frontend** built with Vite + Tailwind CSS  
- 🛍️ Product browsing, filtering, and category-based listings  
- 🛒 Add to Cart, Checkout, and Order Tracking system  
- 👤 User Authentication and Profile Management  
- 🧾 Seller Dashboard to manage products and orders  
- 💬 Contact form and email link (direct Gmail integration)  
- 🔗 Fully working “Follow Us” section with real social media redirects

---

## 🧰 Tech Stack

| Layer | Technology |
|-------|-------------|
| Frontend | React (Vite) + Tailwind CSS |
| Backend | Node.js + Express |

## ⚙️ Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/Kush146/Greencart-Fullstack.git
cd Greencart-Fullstack
```

### 2️⃣ Install dependencies
For both frontend (`client`) and backend (`server`):
```bash
cd client
npm install
cd ../server
npm install
```

### 3️⃣ Setup environment variables
Create `.env` files in both the `client` and `server` directories.  
Example for server:
```env
MONGODB_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

---

### 4️⃣ Run the project locally

**Backend**
```bash
cd server
npm run dev
```

**Frontend**
```bash
cd client
npm run dev
```

Open your app at:  
👉 http://localhost:5173/
